## Stations: frequency + PI, with a name and an area

One node can now hear two P4 regions that report the same PI code. P4 Örebro on 102.8 and P4 Värmland on 103.5 both report PI 0xE224 and PS "P4 SR".

- **A station is a frequency and a PI together**, e.g. `102800/E224`. Messages from two stations are never merged, even when the PI is the same. The stations list, the search filter and push rules tell them apart. A push rule with only a PI still matches every station with that PI.
- **Admin → Stationer** (new) lists every station heard, with its frequency, PI, PS, message count and the nodes that hear it.
  - **Name:** taken from RDS the first time it is seen: Long PS, or one of the 25 P4 regions named in the RadioText ("Du lyssnar på P4 Örebro"). Programme names ("P4 Extra") are never taken. *Ändra namn* sets the name by hand.
  - **Area:** where the station's traffic messages are placed on the map. It can be a county ("Örebro län", read from its seat) or "Ort, Län". It is suggested from the name, and *Använd …* accepts the suggestion. A station without an area is placed around the node's location, as before.
- **The name is shown everywhere**: on the node card ("P4 Örebro · 102,8 MHz" instead of "P4 SR"), in the message cards and the event page, in search, on the map, in pushes (`station.name`) and in MQTT payloads (`station.name`, `station.key`). The MQTT topics are unchanged.
- **The map has a station filter** when more than one station has placed messages. Each incident shows the stations that named it.
- **API:** `GET /api/v1/stations` gives each station's `station_key`, `display_name`, `area` and `suggested_area`. `PATCH /api/v1/station-settings` (admin) sets the name and area. `GET /api/v1/events?station=102800/E224` filters on one station.

Existing events, imported ones included, get their station when the aggregator starts. Messages that were already placed keep their places. **Admin → Karta** rebuilds the map so they are placed again from each station's area.

Update with `docker compose pull && docker compose up -d`. Then open **Admin → Stationer** and check each station's name and area.

**Known limitation:** the retained MQTT topics are still keyed by PI (`E224/traffic/ta`, `E224/traffic/transcription`), so two stations with the same PI share them.
