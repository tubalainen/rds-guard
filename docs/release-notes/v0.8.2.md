## Better pins from the same answers

Measured by replaying Claude's saved answers for the 61 labelled messages, precise pins go from 79 % to 91 %; the rules engine from 55 % to 57 %.

- **The ends of a stretch are towns.** "E18 mellan Kristinehamn och Karlskoga" could use a farm called Karlskoga near Kil, which put the pin at Forshaga. When a name is also a town, the town is used.
- **The place named at a stretch wins over the stretch** when it is more precise: "Rv 61 mellan Arvika och Fagerås, i höjd med Brunsberg" is Brunsberg (±800 m), not the whole stretch (±19 km). The same for a town on the stretch ("vid Skattkärr") and a town at one end ("strax innan Töcksfors").
- **A wrong pick among same-named places is caught.** If Claude picks a place of the right name that is far from the stretch or town, another place of that name that fits is used.

Pins placed before this version stay where they are. **Admin → Karta → Bygg om kartan** places every stored message again with this version.
