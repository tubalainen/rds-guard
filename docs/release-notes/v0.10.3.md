## The map is not doubled by a new import

Deleting a node in Admin deleted its messages but left their incidents on the map. Importing the same history again then added the whole map once more: on docker01 every incident was there three times (267 instead of 89), and the ones linked to an ongoing Trafikverket deviation filled "the last 12 hours" with copies.

- **Deleting a node now also takes its messages off the map**, and the incidents and area warnings only they mentioned.
- **The import never adds a message's incidents a second time**: messages already on the map are skipped.

## Upgrading

`docker compose pull && docker compose up -d`.

The copies already on the map stay until the map is rebuilt: **Admin → Karta → Bygg om kartan** deletes every incident and places the stored messages again (with Claude about 1.5 öre per message).
