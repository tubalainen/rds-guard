## The dongle check measures the data rate after the dongle has started; iq_side with an Airspy's stages by hand

- **Data rate:** in v1.0.7 and v1.0.8 the start-up check counted from the very first block, including the slow moments while the dongle starts. On docker01 an Airspy R2 measured 2.09 of 2.5 MS/s (84 %), close to the warning at 80 %, though RDS ran at full rate. The rate is now measured once the first 0.3 s have passed, so a dongle that starts slowly no longer gets a false "too little data" warning.
- **`iq_side.py` takes an Airspy's LNA, Mixer and VGA by hand** (`--lna 4 --mixer 3 --vga 9`), as in `receivers.yml`. Before, it could only use the linearity gain. Some stations are only heard with the stages set by hand. With the satellite stopped:

```bash
docker compose run --rm --no-deps rds-guard python3 iq_side.py 102.8M --serial 0x… --lna 4 --mixer 3 --vga 9
```

Update with `docker compose pull && docker compose up -d`.
