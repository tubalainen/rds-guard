## Satellite and aggregator on one host

The first step towards one setup for everyone: a satellite that only receives and records, and an aggregator that does everything else ([plan](../plans/satellit-aggregator.md)). Nothing is removed in this release.

- **`docker-compose.yml` now runs both** the satellite and the aggregator on one host, sharing one `.env`. The satellite reports to the aggregator over the compose network as soon as `UPLINK_TOKEN` is set, and then only records (`LOCAL_PROCESSING=false`). MQTT and push come from the aggregator under the satellite's old prefix (`rds`), so Home Assistant keeps working. The satellite-only file is now `docker-compose.satellite.yml`.
- **Import your history:** `python3 -m aggregator.import_satellite /import/events.db /import/audio --node "docker01"` copies events, audio, transcriptions, the map's incidents and area warnings, Trafikverket links, the push log and your push rules into the aggregator. Nothing is transcribed or pushed again, it can run again safely, and `--dry-run` shows what it would do. See the README, *Moving an existing installation to satellite + aggregator*.
- **Where a node is, set in Admin:** *Admin → Noder → Ändra plats* sets the node's place ("Ort, Län") for the map. It wins over the `NODE_LOCATION` the node reports; empty goes back to that one.
- **More on the node card:** PI, TA/TP, uptime, receiver state and where the node was found.
- **The measuring tools in the aggregator's image:** `docker compose exec aggregator python3 /app/tools/eval_geolocation.py` and `measure_geolocation.py`. `--stored` and `--import` also read the aggregator's `/api/v1/events`.

## Upgrading

A satellite-only host (a friend's Raspberry Pi): nothing changes; if you fetch the compose file again, take `docker-compose.satellite.yml`.

To move a standalone installation to satellite + aggregator, follow the README section above. In short:

```bash
curl -fsSLo docker-compose.yml https://raw.githubusercontent.com/tubalainen/rds-guard/master/docker-compose.yml
docker compose pull && docker compose up -d
docker compose exec aggregator python3 -m aggregator.import_satellite /import/events.db /import/audio --node "docker01"
# put the printed UPLINK_TOKEN=… in .env, then
docker compose up -d
```

The aggregator's web UI is on port 8080; the satellite's stays on 8022 until v1.0.
