## An empty map points to the history

After moving to the aggregator, its map looked empty although the import had brought every incident: they are older than 12 hours, and the map shows the last 12 hours unless **Visa historiska händelser** is ticked. That choice is remembered by the browser per web address, so the aggregator's page (port 8080) starts without it even when the satellite's page (8022) had it on.

- **When nothing was mentioned in the last 12 hours, the map's list now says so and offers a button, "Visa historiska händelser"**, which ticks the box (and remembers it), on both the satellite's and the aggregator's map.

## Upgrading

`docker compose pull && docker compose up -d`. Nothing needs to be imported again.
