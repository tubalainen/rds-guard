## Dark theme, logo and an Admin page

Three changes to the web interface, for both the satellite and the aggregator:

- **Dark theme by default.** The whole interface is dark again, with colours chosen for contrast on a dark background: traffic and VMA labels, the calendar scale, the audio player's waveform. *Ljust tema* in the footer switches to the light theme; the choice is remembered in the browser.
- **A logo of its own.** A yellow warning triangle with a transmitter symbol in the header, as the browser tab icon and as the icon when the page is saved to a phone's home screen.
- **Admin page behind a password.** The push rules (*Aviseringar*) have moved to a new **Admin** page that needs the password in `ADMIN_PASSWORD`. On the aggregator, node management (*Noder*) is there too. A login lasts 12 hours; five wrong passwords in 15 minutes lock the login for a while. Without `ADMIN_PASSWORD` the Admin page is switched off, and rules already saved keep sending.

### New setting (`.env`, satellite and aggregator)

| Variable | |
|---|---|
| `ADMIN_PASSWORD` | Password for the Admin page. Empty (the default) switches Admin off: push rules and, on the aggregator, nodes cannot be changed from the web UI |

## Upgrading from v0.4.2

Set `ADMIN_PASSWORD` in `.env` if you want to change push rules or (aggregator) add nodes from the web UI, then update as usual with `docker compose pull && docker compose up -d`. Without it, everything else works as before.
