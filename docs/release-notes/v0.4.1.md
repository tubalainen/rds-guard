## Simpler installation: no clone needed

v0.4.1 changes only the documentation. The code and the images are the same as in v0.4.0.

Both the satellite and the aggregator run from a ready-made image, so the installation instructions no longer clone the whole repository. You download two files and pull the image:

**Satellite** (main README → *Quick start*):

```bash
mkdir rds-guard && cd rds-guard
curl -fsSLo docker-compose.yml https://raw.githubusercontent.com/tubalainen/rds-guard/master/docker-compose.yml
curl -fsSLo .env https://raw.githubusercontent.com/tubalainen/rds-guard/master/.env.example
docker compose pull && docker compose up -d
```

**Aggregator** (`aggregator/README.md` → *Quick start*):

```bash
mkdir rds-guard-aggregator && cd rds-guard-aggregator
curl -fsSLo docker-compose.yml https://raw.githubusercontent.com/tubalainen/rds-guard/master/aggregator/docker-compose.yml
curl -fsSLo .env https://raw.githubusercontent.com/tubalainen/rds-guard/master/aggregator/.env.example
docker compose pull && docker compose up -d
```

Edit `.env` before you start. Cloning is only needed if you want to build an image yourself.

## Upgrading from v0.4.0

Nothing to do. An existing installation, cloned or not, keeps working; update as usual with `docker compose pull && docker compose up -d`.
