## A dongle that hears nothing is noticed, and the RTL-SDR Blog V4 works

- **The RTL-SDR Blog V4 works.** The satellite image now uses the RTL-SDR Blog driver (v1.3.6) instead of Debian's `rtl-sdr`. Debian's driver tunes the V4's R828D tuner wrongly, so a V4 heard nothing. Every other RTL2832U dongle works as before.
- **A dongle that hears nothing is said so.**
  - When no frequency shows a clear 19 kHz pilot at any gain, the calibration stops after the sweep. It no longer runs four decoding checks in vain. The log says `no FM station heard on this dongle at any gain … antenna, FM filter or driver?`.
  - The dongle keeps its earlier settings and tries again in 3 hours.
  - The node card shows *misslyckades: ingen FM-signal hörs*.
- **Health needs RDS.** A satellite whose receivers run but have decoded nothing from any station for 5 minutes is now `unhealthy`. There is a grace period after the start, and a receiver that is calibrating counts as fine.
- **The node card shows stations without RDS** (*ingen RDS: 102.8M*). In v1.0.1 the list was not saved with the calibration, so the card never showed it.

Update with `docker compose pull && docker compose up -d`.
