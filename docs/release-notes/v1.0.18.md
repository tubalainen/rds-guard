## Stations: the regional PI takes the area of its frequency

On Saturday morning 102.8 sent P4 Örebro's regional PI, 0xE424, for the first time on docker01 (103.5 sent 0xE824 at the same time). It became a new station, named P4 Örebro from its PS "P4 Örebr", but without an area. Its traffic messages would have been placed around the node's location (Karlstad), not around Örebro, although 102800/E224 had been named P4 Örebro with the area "Örebro län".

- **A station with a name but no area uses the area of a station on the same frequency with the same name.** 102800/E424 "P4 Örebro" now uses "Örebro län" from 102800/E224. This happens only when those stations agree on one area. An area set for the station itself still wins. Admin → Stationer shows where the area comes from.
- Unchanged from v1.0.12: a station with no name of its own takes both the name and the area of its frequency.

Only the aggregator image changed. Update with `docker compose pull && docker compose up -d`.
