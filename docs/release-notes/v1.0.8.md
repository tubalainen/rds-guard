## The dongle check measures the data rate after the dongle has started

- In v1.0.7 the start-up check counted from the very first block, including the slow first moments while the dongle starts. On docker01 an Airspy R2 measured 2.09 of 2.5 MS/s (84 %), close to the warning at 80 %, though RDS ran at full rate. The rate is now measured only once the first 0.3 s have passed, so a dongle that starts slowly no longer gets a false "too little data" warning.

Update with `docker compose pull && docker compose up -d`.
