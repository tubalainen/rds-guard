## Transcribe the stored messages again

A new tool transcribes every stored recording again, oldest first, with the receiver's own engine and settings (ElevenLabs with the local place names as keyterms, or KB-Whisper). It shows the count and the cost first and changes nothing without `--yes`; it prints a line per message.

```bash
docker compose exec rds-guard python3 /app/tools/retranscribe.py
docker compose exec rds-guard python3 /app/tools/retranscribe.py --yes
```

`--limit 5` tries a few first, `--since 2026-11-20` takes only newer messages, `--engine local` uses KB-Whisper on the CPU (free). ElevenLabs is about 2–3 öre per message, from the plan's credits.

The map is not touched. Afterwards, **Admin → Karta → Bygg om kartan** places every message again from the new texts, with the roads and Trafikverket's places from v0.9.0.

## Upgrading

`docker compose pull && docker compose up -d`
