## ppm measured from the gain sweep

- **The frequency error (ppm) is now measured during the gain sweep, not before it.** The old order measured it on a single 3-second capture at a guessed gain (8.7 dB). There a weak station could be too faint and a strong one could clip.
  - Now every step that does not clip, and every station with a clear pilot, gives an estimate.
  - The ppm is the median of all of them. The log says how many it used (`ppm -2 (median of 20 measurements …)`).
  - The decoding checks then run with that correction.
- **The calibration takes a few seconds less:** the separate ppm capture is gone.
- **Fixed values from `receivers.yml`:**
  - A fixed `ppm:` is used throughout the sweep.
  - With a fixed `gain:`, the ppm is measured at that gain.

Update with `docker compose pull && docker compose up -d`. To measure again with the new order, run **Admin → Noder → Kalibrera om**.
