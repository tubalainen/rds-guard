## Stations: "P4 SR" gets the name of its frequency

On docker01 every station showed as "P4 SR" with PI 0xE224, while a car radio said "P4 Värmland". The messages heard since October show why: 103.5 sends its own PI and PS ("P4 Värml") in the regional hours, and switches to the shared PI 0xE224 and PS "P4 SR" when P4 sends the common programme (lunchtime, evenings, nights and weekends).

- **A cut-short PS names its region.** PS has only 8 characters, so "P4 Värml" and "P4 Örebr" were not recognised as P4 Värmland and P4 Örebro. A cut that fits only one of the 25 regions now counts as its name, and suggests its county as the area. Stations already heard get the name when the aggregator starts.
- **A station with no name of its own takes the name of its frequency.** 103500/E224 ("P4 SR") is shown as P4 Värmland once 103.5 has been heard as "P4 Värml". It also uses that station's area for placing messages on the map. This happens only when the named stations on that frequency agree on one name. A name set in Admin still wins. Admin → Stationer shows where the name comes from.
- A frequency never heard with its regional PS (100.3 on docker01 so far) stays "P4 SR" until it is, or until you name it in Admin.

Update with `docker compose pull && docker compose up -d`.
