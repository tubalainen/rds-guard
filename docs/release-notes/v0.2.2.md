## Better Swedish transcription

v0.2.2 makes traffic announcements noticeably easier to read in alerts and the web UI:

- **ElevenLabs Scribe is the default engine.** On real P4 traffic announcements it dropped fewer place names and details than local Whisper, wrote road and phone numbers as digits (`länsväg 734`, `020-99 94 44`) and took 2–5 s per clip. It costs about 2–3 öre per announcement (≈ USD 0.20–0.24 per hour of audio).
- **Local fallback.** If the API fails, or no API key is set, the audio is transcribed locally, so alerts always get text.
- **Swedish local model.** The local engine now uses the National Library of Sweden's KB-Whisper small, in its verbatim *strict* style, bundled in the image. On Swedish it makes about a third as many errors as OpenAI's `small` model at the same CPU cost.
- **Cleaner audio.** New recordings have the FM pre-emphasis removed and are limited to the speech band, so they sound less sharp and are easier to recognise.
- **Fix:** a freshly built image could not transcribe at all, because PyAV 19 is incompatible with faster-whisper. PyAV is now pinned below 19.

## Upgrading from v0.2.x

Pull the new image and restart (`docker compose pull && docker compose up -d`). Then:

1. **To use ElevenLabs**, add your key to `.env` and restart:
   ```env
   ELEVENLABS_API_KEY=<your key>
   # Optional: words to listen for, comma-separated
   # ELEVENLABS_KEYTERMS=E18, Karlstad, Bergviksmotet, Våxnäsmotet
   ```
   Without a key nothing changes in how it works: transcription stays local. To stay local even with a key, set `TRANSCRIPTION_ENGINE=local`. Audio is sent to ElevenLabs (processed in the US by default).
2. **Check `TRANSCRIPTION_MODEL`.** If your `.env` has `TRANSCRIPTION_MODEL=small` (the old example file did), you keep OpenAI's model. Clear the value (`TRANSCRIPTION_MODEL=`) to use the bundled Swedish model.
3. Models you choose yourself are now cached in `rds-data/models`, so such a model is downloaded once more after the upgrade.

The image is about 240 MB larger because of the bundled model. The aggregator takes the same settings (`ELEVENLABS_API_KEY` etc. in `aggregator/.env`).

### New settings

| Variable | Default | |
|---|---|---|
| `TRANSCRIPTION_ENGINE` | `elevenlabs` | was `local`; runs as `local` without a key |
| `ELEVENLABS_API_KEY` | | ElevenLabs API key |
| `ELEVENLABS_MODEL` | `scribe_v3` | or `scribe_v2` |
| `ELEVENLABS_KEYTERMS` | | words to listen for (+20 % cost) |
| `ELEVENLABS_TIMEOUT` | `60` | seconds |
| `TRANSCRIPTION_FALLBACK` | `local` | `local` or `none` |
| `TRANSCRIPTION_PROMPT` | | vocabulary hint for local Whisper |
| `TRANSCRIPTION_BEAM_SIZE` | `5` | `1` is faster on CPU |
| `TRANSCRIPTION_CPU_THREADS` | `0` | `0` = automatic |
