## History on the map

The **Karta** page has a new tick box, **Visa historiska händelser**. With it the map shows every incident still stored (`EVENT_RETENTION_DAYS`), not only the last 12 hours. Satellites and the aggregator both have it.

- Incidents older than 12 hours are **violet**; the last 12 hours stay red and grey as before. An incident becomes history by itself once 12 hours have passed since it was last mentioned.
- The list beside the map is grouped by day, and each incident shows when it was mentioned ("24 nov. 08:10–09:40").
- The choice is remembered in your browser. A place label on an older event in *Arkiv* or *Sök* opens the map with the history shown.

### Older messages are placed once

The first time the history is shown, the messages stored before the map existed (before v0.5.0, or while `NODE_LOCATION` was not set) are placed on the map, in the background; the map shows how far it has come. Each message is placed as at the time it was broadcast, so messages about the same incident join one pin that day. No push or MQTT alerts are sent for them.

It uses the same engine as new messages. With Claude on (`GEO_ENGINE=claude` and `ANTHROPIC_API_KEY`) that costs about 1–3 öre per stored message, a few kronor for a few hundred; without a key the free local rules engine places them. On the aggregator, messages from a node without `NODE_LOCATION` wait until the node reports one.

New API: `GET /api/incidents?history=1` and `POST /api/incidents/backfill` (aggregator: `/api/v1/...`).

## Upgrading from v0.5.0

`docker compose pull && docker compose up -d`. No new settings and no database changes.
