## The aggregator's map shows the map again

The aggregator's map showed only "Access blocked" tiles from OpenStreetMap. Its pages sent `Referrer-Policy: same-origin`, so the browser asked tile.openstreetmap.org for tiles without a `Referer`, and OSM refuses such requests under its tile usage policy. The incidents themselves were drawn correctly; only the background was missing.

- **The aggregator now sends `Referrer-Policy: strict-origin-when-cross-origin`**, the browsers' own default: OSM sees only the page's origin (such as `http://docker01:8080`), never the path. The satellite was not affected.

## Upgrading

`docker compose pull && docker compose up -d`, then reload the map page.
