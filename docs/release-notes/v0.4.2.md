## Search and event cards

Two fixes in the web interface, for both the satellite and the aggregator:

- **Search with no filter lists everything.** Opening *Sök* with *Alla* and *Hela perioden* selected and an empty search box used to show only a placeholder. It now lists every stored event, newest first, with *Visa fler* loading 50 at a time. The search suggestions are still shown above the list.
- **Event cards show the whole text.** Transcriptions and RadioText in *Arkiv* and *Sök* were cut after three lines with "…". The cards now always show the full text.

This release also includes the dependency updates merged since v0.4.1 (PyAV is kept below 19, which faster-whisper does not yet support).

## Upgrading from v0.4.1

Nothing to do. Update as usual with `docker compose pull && docker compose up -d`.
