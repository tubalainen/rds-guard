## Airspy: LNA, Mixer and VGA by hand

- **An Airspy's three gain stages can be set by hand in `receivers.yml`**, each optional: `lna:` (0–14), `mixer:` (0–15), `vga:` (0–15).

  ```yaml
    - serial: "0x62CC68FF3584805B"
      frequencies: [102.8M]
      lna: 4
      mixer: 3
      vga: 9
  ```

  - **All three set:** used as given, with no gain calibration. A `gain:` is then ignored, with a warning.
  - **One or two set:** those stay fixed and the calibration sweeps the others. Settings that come out the same are measured only once.
  - **None set:** as in v1.0.5. The linearity gain 0–21 is calibrated, and each step is a fixed LNA/Mixer/VGA combination.
- **The AGC is turned off before a run by hand.** The tuner keeps LNA and Mixer AGC between programs until it is unplugged, so an AGC that SDR++ or SDR# left on would otherwise override the values.
- **Changing or removing a fixed value calibrates that receiver again.**
- **The log shows what runs:** `gain LNA 4, Mixer 3, VGA 9 (by hand)` or `(linearity 8)`. The node card shows the gain step marked *manual*, not the three values.
- Invalid values, e.g. `lna: 15`, stop the start with a message. On an RTL-SDR they are ignored, with a warning.

Update with `docker compose pull && docker compose up -d`.
