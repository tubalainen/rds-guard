## The web page picks up a new version at once

After the update to v1.0.12 the browser kept running the old `aggregator.js`. Admin → Stationer said "namn PS" for a name that came from the other PI on the same frequency, until a hard reload (Ctrl+F5). The aggregator sent no cache rules for its files, so the browser guessed how long it could keep them.

- **The page links its scripts and stylesheets with the version** (`/static/js/aggregator.js?v=v1.0.14`), so a new version is a new address and is always fetched.
- **The page and everything under `/static/` are sent with `Cache-Control: no-cache`.** The browser asks the server each time and gets a short "not modified" when nothing has changed, so the page loads just as fast.

Update with `docker compose pull && docker compose up -d`. This time, reload the page once with Ctrl+F5 after updating. From then on the browser picks up new versions on its own.
