## Admin page, dark theme and a logo

- **Admin page behind a password.** The push rules (*Aviseringar*) now sit on a new **Admin** page that needs the password in `ADMIN_PASSWORD`, on both the satellite and the aggregator. On the aggregator, node management (*Noder*) has moved there too. All `/api/notify*` calls, and the aggregator's `/api/v1/nodes*` calls, need a login. A login lasts 12 hours, and five wrong passwords in 15 minutes lock the login for a while. The old address `#/aviseringar` leads to the new page.
- **Dark theme by default.** The web interface is dark by default. *Ljust tema* / *Mörkt tema* in the footer switches theme, and the choice is remembered in the browser.
- **Logo.** RDS Guard has its own icon, a warning triangle with a transmitter, in the browser tab, in the header and in the README.

## Upgrading from v0.4.2

Set a password for the Admin page in `.env` on each installation where you want to change push rules (and, on the aggregator, manage nodes):

```
ADMIN_PASSWORD=choose-a-long-password
```

Without it the Admin page is switched off. Rules that are already saved keep sending, but they can't be changed until a password is set.

Then update as usual with `docker compose pull && docker compose up -d`.
